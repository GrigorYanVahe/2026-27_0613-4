# RU
# Student Submissions Dashboard 🎓

Локальный веб-интерфейс для преподавателя, позволяющий в реальном времени проверять статус выполнения студенческих работ по структуре папок репозитория.

## 📂 Структура данных
Приложение ожидает следующую иерархию папок в корне проекта:
* `[Имя_Студента]/`
  * `dynamic_web/` (задания `result-1` — `result-4`)
  * `graphic_Interfaces/` (задания `result-1` — `result-2`)
  * `java_script/` (задания `result-1` — `result-5`)

*Критерий сдачи:* Если внутри папки `result-X` находится проект (папка не пуста), задание засчитывается как выполненное.

## 🚀 Как запустить

1. Откройте файл **`index.html`** в любом современном браузере (Chrome, Edge, Opera).
2. Нажмите кнопку **«Выбрать корневую папку с работами»** (или используйте поле ввода).
3. Выберите корневую папку, в которой лежат папки всех студентов.

# EN
# Student Submissions Dashboard 🎓

A lightweight, local web interface for college instructors to track and review student assignment submissions organized from GitHub repositories.

## 📂 Folder Structure
The app expects the following directory structure in your root folder:
* `[Student_Name]/`
  * `dynamic_web/` (tasks `result-1` to `result-4`)
  * `graphic_Interfaces/` (tasks `result-1` to `result-2`)
  * `java_script/` (tasks `result-1` to `result-5`)

*Grading criteria:* A task is automatically marked as completed (green checkmark) if the corresponding `result-X` folder contains the student's project files.

## 🚀 How to Use
1. Open the **`index.html`** file in any modern web browser (Chrome, Edge, Firefox, etc.).
2. Click the **"📁 Select Root Folder"** button.
3. Choose the main directory containing all your student folders.
